### Business Loan Approval System Using PostgreSQL

Developed a Business Loan Approval System using PostgreSQL to analyze historical borrower data and support data-driven loan assessment for a central banking institution. The main objective of this project was to organize borrower information, evaluate historical loan performance, and identify patterns related to loan repayment and default risk.

**Key Responsibilities:**

- **Data Management:** Imported and organized historical borrower and loan records into PostgreSQL tables for efficient data storage, retrieval, and analysis.

- **Data Cleaning:** Identified missing values, duplicate records, inconsistent formats, and invalid entries to improve data quality and reliability.

- **Data Exploration:** Analyzed important loan attributes, including loan amount, loan term, number of employees, industry classification, and loan repayment status.

- **SQL Querying:** Used SQL commands, filtering, sorting, aggregate functions, GROUP BY, HAVING, subqueries, and JOINs to retrieve meaningful information from the database.

- **Loan Performance Analysis:** Examined historical loan outcomes, including loans paid in full and loans charged off, to understand repayment patterns.

- **Risk Assessment:** Investigated borrower and loan characteristics associated with repayment difficulties to identify potential risk factors and support informed lending decisions.

- **Business Insights:** Generated analytical summaries to understand loan distributions, repayment trends, and default-related patterns using SQL queries and aggregate calculations.

- **Decision Support:** Structured the analysis to help stakeholders evaluate historical lending performance and make more informed loan assessment decisions.

**Tools and Technologies:** PostgreSQL, SQL, pgAdmin, and historical SBA loan dataset.

**Project Outcome:**

This project demonstrates the practical use of PostgreSQL for financial data management, data cleaning, and SQL-based analysis. It provides insights into historical lending patterns and borrower repayment behavior, helping establish a foundation for more efficient loan assessment and risk management. The project can be further enhanced by integrating machine learning models to predict loan default probabilities and generate loan approval recommendations. Overall, it strengthened my skills in database management, SQL querying, data analysis, and transforming raw financial data into meaningful business insights.
